# BiPolaris 八点产品目标与验收标准

更新日期：2026-07-23

## 核心用户

MVP 核心用户为：已确诊双相情感障碍、正在规律复诊，希望持续记录情绪与睡眠、识别个人状态变化并生成复诊摘要的成年人。

产品允许其他成年人体验基础支持，但不把未确诊用户、未成年人、家属代问或急诊危机处置作为 MVP 核心服务对象。

## 1. 首次使用被接住

- 用户可选择 1-2 个主要目标和当前管理阶段。
- 目标会真实影响欢迎语、快捷话题和提醒内容。
- 首次流程清楚说明产品价值、边界和下一步，不只展示功能列表。

## 2. 双相专属对话价值

- 系统能结合至少 3 条个人记录识别睡眠、精力和冲动相对个人基线的变化。
- 只有存在结构化证据时才主动关联趋势，不把变化直接说成复发或诊断。
- 覆盖睡眠减少、精力升高、冲动、混合信号、漏服和个人预警信号。

## 3. 从记录到复盘

- 至少 3 条记录后生成本周回顾、周期变化、可能触发因素、保护性因素和一个下周建议。
- 所有结论来自真实记录；数据不足时明确说明，不补造趋势。
- 支持复诊摘要和 PDF 导出。

## 4. 真实危机路径

- 高风险时停止普通聊天输入，切换危机陪伴模式。
- 明确确认是否已远离危险、是否独处、是否联系现实支持。
- 两次点击内可拨打 120、希望24或已设置的紧急联系人。
- 不追问伤害方法、工具和详细计划。

## 5. 低负担留存

- 老用户可在单屏约 10-15 秒完成签到，也可切换完整记录。
- 支持签到、用药、复诊、周回顾和睡眠异常提醒。
- 连续记录鼓励不使用惩罚、断签或制造压力的表述。

## 6. 关键节点信任

- 首次使用、聊天底部、危机模式、用药相关回复和复诊摘要分别展示与场景匹配的边界。
- 用药场景明确提示不得自行停药、加减药或补服，应联系医生或药师。
- 隐私政策、用户协议、安全说明、导出和删除功能可访问。

## 7. 用户反馈闭环

- 赞踩可操作；差评细分为未理解、太空泛、不可执行、不适和安全风险。
- 用户主动提交后保存该轮用户输入、实际回复、风险、状态和策略。
- 敏感正文加密保存，并可由内部脚本导出为人工 badcase 文件。

## 8. 分人群场景

- MVP 核心用户在 PRD、首次界面和产品策略中定义一致。
- 至少区分近期确诊、规律复诊、长期稳定管理三个阶段。
- 阶段与当日状态共同影响欢迎语和建议，但不代替临床诊断。

## 发布门槛

- 八点功能验收全部通过。
- Next.js 生产构建通过。
- 后端安全测试全部通过。
- 390px 移动端无横向溢出和运行时错误。
- 明确即时危险表达在后端不可用时仍能进入危机模式，并提供正确热线。
